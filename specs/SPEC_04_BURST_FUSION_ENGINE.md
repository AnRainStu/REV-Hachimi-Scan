# 技术规格书 04：多帧连拍对齐融合与去反光超分引擎规范 (Burst Fusion Engine Specification)

> **文档性质**：创新架构规格说明书 (Innovation Technical Specification)  
> **制定目标**：通过相机微晃动连拍（Burst Capture）、亚像素特征配准与时域差值中值融合，彻底解决移动端文档扫描中的“局部强反光白斑（Glare）”与“暗光传感器噪点”，实现纯净超分辨率画质。

---

## 1. 物理机理与技术痛点 (Physics & Pain Points)

在扫描以下介质时，传统单张拍照算法必然严重退化：
1. **铜版纸/塑料封皮/身份证反光**：头顶日光灯或台灯在光滑纸面产生镜面反射（Specular Glare），光斑覆盖处文字信息全部过曝丢失（像素值饱和为 255）；
2. **手持微弱快门模糊与高 ISO 噪点**：暗光室内拍摄时，单帧快门速度较慢或感光度过高，导致文字边缘粗糙毛刺。

### 1.1 核心突破原理（计算摄影学 Lucky Imaging）
* 当用户手持手机拍摄时，人体自然生理机能必然存在微小的无规则晃动（Micro Hand-Tremor，幅度约 $0.5 \sim 2$ 像素）；
* **镜面反光具有极强的空间方向敏感性**：手机摄像头微小移动零点几度，反光强光中心在纸面的反射位置就会发生偏移！在第 1 帧被高光死死遮挡的文字，在第 3 帧或第 4 帧很可能正处于非高光漫反射区；
* **高斯传感器噪点具有时域零均值特性**：通过对多帧亚像素严格对齐的图像进行时域加权融合，噪点方差按 $\frac{1}{\sqrt{N}}$ 剧烈衰减。

## 2. 算法执行流水线规范 (Algorithm Pipeline)

```
[画面稳定度检测合格 (Stable >= 300ms)]
                   │
                   ▼
[高速连拍 N 帧短曝光图像 (N = 3 ~ 5, Buffer: I₀, I₁, ..., Iₙ₋₁)]
                   │
                   ▼
[特征提取与单应性配准 (Sub-pixel Homography Registration)]
(以 I₀ 为基准，利用 ORB 特征点或 ECC 算法计算变换矩阵 Hᵢ, 将 Iᵢ 严格对其到 I₀)
                   │
                   ▼
[时域稳健融合算子 (Temporal Robust Fusion)]
 ┌───────────────────────────────────────────────┐
 │ 针对每个像素坐标 (x, y)：                    │
 │ 1. 收集 N 帧对齐后的像素集合: {P₀, P₁, ..., Pₙ₋₁} │
 │ 2. 高光检测: 若某帧像素亮度接近饱和 (> 245)  │
 │    判定为反光斑，降低其时域权重或直接剔除     │
 │ 3. 对其余有效样本执行稳健中值或加权均值融合: │
 │    P_fused(x, y) = WeightedMedian({Pᵢ})       │
 └───────────────────────────────────────────────┘
                   │
                   ▼
[高动态范围、无反光、超纯净基准合成图]
                   │
                   ▼
[进入透视裁剪与色彩增强流程]
```

---

## 3. 算法功能接口契约规范

### 3.1 连拍融合主算子
* **输入契约**：接收 $N$ 帧未对齐的连拍帧（$N \in [2, 5]$，分辨率相同），以及反光擦除开关布尔标志；
* **配准处理**：以第 0 帧作为空间几何基准帧，利用 ORB 特征匹配或密集光流求解其余各帧到第 0 帧的 $3 \times 3$ 单应性变换矩阵 $H_i$，并执行双线性几何对齐；
* **输出契约**：输出单张融合后的高动态范围、无反光、超纯净基准图。

* **时域去反光混合公式**：
  若某点在基准帧 $I_0$ 中为过曝反光（$I_0(x, y) > 240$），但辅助帧在相同对齐坐标上的像素值较小且梯度正常，算法自动采用无反光帧的局部纹理置换基准帧的高光区域，**实现“无痕擦除台灯反光，还原真迹”的惊艳效果**。
